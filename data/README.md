# Data

This folder includes data files used by our project code. It's split by **type** (vaccine coverage vs. province/territory
relation data) and, within coverage, by **provenance** (raw inputs vs. files
generated by code in this repo).

```
data/
├── coverage/       # measles vaccine coverage estimates
│   ├── raw/        # original source data (not produced by this repo)
│   └── generated/  # coverage files written by code in this repo
└── pt-relation/    # province/territory population & socioeconomic indicators
```

## `coverage/raw/`

Original vaccine coverage inputs, collected from external sources and never
modified by repo code. Read primarily by `1_collate-data.qmd` and
`code-demo.qmd`.

| File / folder | Description |
|---|---|
| `measles_raw/` | Province/territory source files (AB, BC, MB, ON, QC adult xlsx/csv) plus immunization schedules and `vax_schedule.csv`. |
| `CNICS-ANICS_raw/` | Raw cNICS/aNICS extracts. |
| `1310087001-eng.csv` | StatCan cNICS by-PT coverage estimates. |
| `measles_CNICS.csv` | cNICS coverage series used in `code-demo.qmd`. |
| `ukhsa-chart-download-mmr1-nations.csv` | UKHSA MMR1 coverage, four UK nations. |
| `ukhsa-chart-download-mmr1-regions.csv` | UKHSA MMR1 coverage, English regions. |
| `vaccination-coverage-byAgeAndSex-overTimeDownload.csv` | StatCan COVID-19 vaccination coverage by age and sex over time; source for the generated `pt-relation/COVID-coverage_5-11.csv`. |

## `coverage/generated/`

Coverage datasets written by the data pipeline.

| File | Produced by | Description |
|---|---|---|
| `measles_vax-coverage-data.csv` | `1_collate-data.qmd` | Collated standardized coverage across all sources. |
| `measles_vax-coverage-data-cleaned.csv` | `2_prepare-data.qmd` | Cleaned coverage dataset (model input). |
| `measles_vax-coverage-data-cleaned_noadults.csv` | `2_prepare-data.qmd` | Cleaned dataset with aNICS (adult) estimates removed. |
| `measles_vax-coverage-data-cleaned_2plus.csv` | `2_prepare-data.qmd` | 2+ dose subset for plot overlays. |

## `pt-relation/`

Province/territory population, lookup, and socioeconomic indicator files. All
are external raw sources except where noted as generated by repo code; read
mainly by `R/extract_province_relation.R`, `R/pt_lookup.R`, `2_prepare-data.qmd`,
and `code-demo.qmd`.

| File | Description |
|---|---|
| `pt_lookup.csv` | PT name / two-letter abbreviation lookup. |
| `popsize.csv` | PT population sizes. |
| `3610040201-noSymbol.csv` | StatCan provincial GDP. |
| `9810009601_databaseLoadingData_StatCanGini.csv` | StatCan provincial Gini index. |
| `health-ineq-data-tool-children-in-low-income-families-LICO-detailed.csv` | Children in low-income families (LICO). |
| `cNICS-vaccine-hesitancy.csv` | Vaccine hesitancy by region. |
| `uk-ONSdownload-regionalgdp.csv` | UK regional GDP (ONS). |
| `uk-officialstatistics-childreninlowincomefamilies.csv` | UK children in low-income families. |
| `ONS_analysingregionaleconomicandwellbeingtrends_fig7.csv` | UK regional Gini (ONS). |
| `COVID-coverage_5-11.csv` | **Generated** by the `ptrelation_covid` target in `_targets.R`; most-recent COVID-19 coverage (5–11 yr, 1+ dose) used as a PT-relation indicator. |
